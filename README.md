# immunomath
a repo to interact with colleagues on the project IHU IMMUN4CARE WP1-3

## 🚀 Guide rapide Git & GitHub pour collaborer

### 1. Cloner le dépôt (récupérer le projet sur son ordinateur)

Ouvre un terminal et tape :
```bash
git clone https://github.com/azerad/immunomath.git
cd immunomath
```

### 2. Créer une branche pour travailler (recommandé)

Pour éviter de modifier directement la version principale :
```bash
git checkout -b mon-nouvel-ajout
```

### 3. Modifier ou ajouter des fichiers

- Ouvre et modifie les fichiers `.tex` ou ajoute de nouveaux fichiers.

### 4. Enregistrer ses changements

```bash
git add .
git commit -m "Explique ce que tu as changé"
```

### 5. Envoyer ses modifications sur GitHub

```bash
git push origin mon-nouvel-ajout
```

### 6. Proposer ses changements (Pull Request)

- Va sur la page GitHub du projet.
- Clique sur "Compare & pull request" pour ta branche.
- Ajoute un commentaire si besoin et clique sur "Create pull request".

### 7. Mettre à jour sa copie du projet

Pour récupérer les dernières modifications faites par les autres :
```bash
git checkout main
git pull origin main
```
